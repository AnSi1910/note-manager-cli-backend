# Серверна частина: Менеджер нотаток

Проєкт розроблений в межах навчальної практики з програмування (Частина 2).

## Використаний технологічний стек
- **Node.js + Express** (серверний фреймворк)
- **Sequelize ORM** (управління базою даних)
- **SQLite** (база даних)
- **Swagger** (документація API)
- **Cors, Morgan, Dotenv** (middleware-стек)

## Інструкція зі встановлення та запуску

1. Встановіть залежності проєкту:
   ```bash
   npm install
2. Створіть файл .env у кореню та додайте порт
   ```bash
   PORT=5000
3. Запустіть сервер:
   ```bash
   npm start
4. Перейдіть по посиланню
   ```bash
   http://localhost:5000/api-docs
